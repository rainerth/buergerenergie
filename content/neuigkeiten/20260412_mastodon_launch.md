Die Bürgerenergie Bösingen-Herrenzimmern ist ab sofort auch auf **Mastodon** erreichbar! Neben unserer Website und Instagram haben wir jetzt einen weiteren Kanal, über den Sie unsere Neuigkeiten verfolgen können — und zwar auf einer Plattform, die hervorragend zu einer Genossenschaft passt.

<!--more-->

## Was ist Mastodon?

Vielleicht haben Sie schon einmal von Twitter gehört — der Plattform, auf der Politiker und Prominente kurze Nachrichten veröffentlichen. Twitter gehört inzwischen einem einzelnen Milliardär und heißt seit 2023 "X". **Mastodon ist die bessere Alternative:** ein soziales Netzwerk, das niemandem gehört.

Das Besondere an Mastodon:

- **Keine Werbung.** Niemand verdient Geld mit Ihren Daten.
- **Kein Algorithmus.** Sie sehen die Beiträge der Menschen und Organisationen, denen Sie folgen — nicht das, was ein Computer für Sie auswählt.
- **Offen und frei.** Mastodon gehört keinem Konzern. Die Software ist kostenlos und wird von einer weltweiten Gemeinschaft entwickelt.

## Wie funktioniert das?

Mastodon funktioniert wie **E-Mail**: Es gibt viele verschiedene Anbieter (in der Mastodon-Welt heißen sie "Server" oder "Instanzen"), aber alle können miteinander kommunizieren. Genauso wie Sie von GMX eine Mail an jemanden bei T-Online schreiben können, können Sie von jedem Mastodon-Server aus allen anderen Nutzern folgen — egal auf welchem Server diese sind.

Dieses Netzwerk aus vielen verbundenen Servern heißt **Fediverse** (von "föderiert" und "Universum"). Weltweit nutzen es über 10 Millionen Menschen.

## Warum passt das zu einer Genossenschaft?

Unser Mastodon-Server heißt **geno.social** und wird von der [Hostsharing eG](https://www.hostsharing.net/) betrieben — einer Genossenschaft, die seit über 20 Jahren gemeinschaftliches Webhosting anbietet. Das passt perfekt zu unseren Werten:

- **Selbstbestimmung** statt Abhängigkeit von Konzernen
- **Transparenz** statt undurchsichtiger Algorithmen
- **Gemeinwohl** statt Gewinnmaximierung
- **Datenschutz** statt Datenhandel

## So einfach geht der Einstieg

Mastodon ausprobieren ist nicht schwieriger als sich bei einem E-Mail-Dienst anzumelden. In wenigen Minuten sind Sie dabei:

### 1. Server wählen

Suchen Sie sich einen Mastodon-Server aus. Unsere Empfehlung für Menschen aus Süddeutschland: **[sueden.social](https://sueden.social/)** — ein freundlicher Server mit regionalem Bezug.

Andere gute Server finden Sie unter [joinmastodon.org/servers](https://joinmastodon.org/servers). Aber denken Sie daran: **Die Wahl des Servers ist wie die Wahl eines E-Mail-Anbieters** — Sie können trotzdem mit allen anderen kommunizieren, egal welchen Server Sie wählen.

### 2. Anmelden

Auf der Website Ihres gewählten Servers klicken Sie auf "Registrieren" und geben Ihren Namen, eine E-Mail-Adresse und ein Passwort ein. Das war's schon!

### 3. App installieren (optional)

Am Computer können Sie Mastodon direkt im Browser nutzen. Für unterwegs gibt es kostenlose Apps:

- **Android:** "Mastodon" im Play Store
- **iPhone/iPad:** "Mastodon" im App Store

### 4. Uns finden und folgen

Suchen Sie nach **@buergerenergie_bhz@geno.social** und klicken Sie auf "Folgen". Ab sofort sehen Sie unsere Beiträge in Ihrer persönlichen Zeitleiste.

Oder besuchen Sie direkt unser Profil: [geno.social/@buergerenergie_bhz](https://geno.social/@buergerenergie_bhz)
